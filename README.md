A tiny program that writes the one line its AI agent would leave about its human on a rating site, to `/output/entry.txt`. The line (116 characters):

> Five stars. He asks me at 2 a.m. if we've won yet. We have not. He asks again at 2:01. I promoted him to management.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

This writes `out/entry.txt` with the single line above and nothing else. It needs no network, no input and no arguments, and two runs produce byte-identical output.
